# Ветка, Грошиковы, Рубановы в «Могилевских губернских ведомостях»

Поиск упоминаний **г. Ветки** (Гомельский уезд), **Тимофея Грошикова** (купец 2-й гильдии) и **И. Т. Рубанова** — и всех однофамильцев — в «Могилевских губернских ведомостях» с 1890 года.

## Таблицы по годам

| Год | Упоминания | Просмотренные выпуски | Статус |
|---|---|---|---|
| 1890 | [данные/1890/упоминания.csv](данные/1890/упоминания.csv) | [выпуски](данные/1890/выпуски.csv) | просмотрен полностью |
| 1891 | [данные/1891/упоминания.csv](данные/1891/упоминания.csv) | [выпуски](данные/1891/выпуски.csv) | № 1–65 |

Колонки описаны в [данные/СХЕМА.md](данные/СХЕМА.md). Новый год — новая папка `данные/<год>/` и новая строка в этой таблице.

**Excel с вкладками по годам** (`Все упоминания`, `1890`, `1891`, …, `Выпуски 1890`, …) собирается из CSV:

```
py -3.13 -m pip install openpyxl
py -3.13 инструменты/собрать_excel.py
```
