# Схема таблиц

Каждый год — своя папка `данные/<год>/` с двумя файлами (UTF-8, разделитель — запятая).
GitHub показывает CSV как таблицу; Excel с вкладками по годам собирается скриптом `инструменты/собрать_excel.py`.

## `упоминания.csv` — одна строка = одна публикация

Повторные публикации («по 2-му разу», «по 3-му разу») — отдельные строки с тем же номером `раздел`.

| Колонка | Что писать | Пример |
|---|---|---|
| `id` | `<год>-<порядковый №>`, по порядку внутри года | `1891-025` |
| `год` | год выпуска | `1891` |
| `раздел` | № раздела в `упоминания.md` (сквозная нумерация) | `34` |
| `объект` | один из: `Ветка`, `Ветковская волость`, `Имение Ветка`, `Грошиков`, `Рубанов` (несколько — через `; `) | `Имение Ветка` |
| `тема` | коротко, одна строка; у повторов — та же, что у 1-й публикации | `Торги банка 27 мая / 11 июня 1891 г.` |
| `выпуск` | № газеты (число) | `65` |
| `дата` | ГГГГ-ММ-ДД по старому стилю, как в газете | `1891-08-14` |
| `файл` | имя PDF | `1891_065.pdf` |
| `стр_pdf` | страница внутри PDF (или диапазон `1–2`) | `4` |
| `стр_газеты` | номер, напечатанный в газете | `246` |
| `рубрика` | раздел газеты | `О публичной и аукционной продаже` |
| `публикация` | `1-я`, `2-я`, `3-я` или пусто | `2-я` |
| `лица` | люди: `Фамилия Имя Отчество, сословие`, через `; ` | `Рубанов Николай Евдокимович, землевладелец` |
| `цитата` | текст в дореформенной орфографии; у повторов — `тот же текст` | |
| `смысл` | 1–2 предложения | |
| `фрагменты` | пути к картинкам, через `; ` | `фрагменты/1891_065_стр246_банк_шапка.png` |

## `выпуски.csv` — журнал просмотра (одна строка = один номер или группа номеров)

| Колонка | Пример |
|---|---|
| `файл` | `1891_065.pdf` |
| `стр_pdf` | пусто, если файл = один номер; `1–5` для сборных файлов |
| `выпуск` | `65` или `71–73` |
| `дата` | `ср, 14 августа 1891` |
| `стр_газеты` | `243–246 + прибавления` |
| `результат` | `ничего не найдено` / `Ветка (…)`; `файла нет`; пометки о неполных сканах |
